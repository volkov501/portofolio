# Folder Bukti Sertifikat

Taruh scan/foto atau PDF sertifikat di folder ini (`public/certificates/`) dengan nama berikut:

| Sertifikat | Nama file |
|---|---|
| BNSP — Computer Network Engineering (2022) | `bnsp-2022.jpg` |
| BNSP — Junior Network Computer Technician (2025) | `bnsp-2025.jpg` |
| BNSP — System & Network Administration (2026) | `bnsp-2026.jpg` |
| TOEIC 770/990 (2022) | `toeic-2022.jpg` |
| P2KPTK2 — Computer Engineering Training (2022) | `p2kptk2-2022.jpg` |

Boleh `.png` atau `.pdf` juga, asal namanya dikabari.

Setelah file ada, isi kolom **Certificate file** (misal `/certificates/bnsp-2022.jpg`) dan **Certificate No.** di Admin → *Education & Certs*. Bisa juga minta Claude yang mengisinya.

Selama kolom itu kosong, kartu sertifikat menampilkan "Credential on request".

Catatan: file di folder `public/` bisa diakses siapa saja. Tutupi data pribadi yang tidak perlu (NIK, tanggal lahir, alamat) sebelum diunggah.
